# Astral vision demo

Open http://localhost:3010/astral-vision/.

A separate interactive concept using the approved Astral tokens. Choose an opening interest, follow the career section, open PAARTH's purpose/approach/trade-off layers, and change perspective through the persistent control. The numerical arrival is a short simulated animation, not actual asset progress; Replay arrival repeats it. During arrival, only the form and numeric progress are visible; other content is hidden and inert. At completion, the same canvas transitions into position and the question appears. Reduced motion skips the timed sequence. Without JavaScript, content remains accessible.

This selected-content demo illustrates layout and interaction direction. It does not implement all career descriptions, every project, live AI, undo, continuous cross-section geometry morphing, or the full final portfolio. Perspective currently changes the career framing and opening destination. The approved design-system files remain unchanged.
